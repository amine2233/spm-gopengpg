# spm-gopengpg

[GopenPGP](https://github.com/ProtonMail/gopenpgp) (the `mssun/gopenpgp` `v2.10.0-passforios` fork) packaged as a prebuilt `Gopenpgp.xcframework` and distributed through Swift Package Manager as a binary target.

Platforms: iOS 13+ (device and simulator), macOS 10.15+.

## Install

### Xcode

1. File > Add Package Dependencies...
2. Enter `https://github.com/amine2233/spm-gopengpg`
3. Choose the dependency rule "Up to Next Major Version" from `2.10.0`.
4. Add the `Gopenpgp` library to your target.

### Package.swift

```swift
dependencies: [
    .package(url: "https://github.com/amine2233/spm-gopengpg", from: "2.10.0"),
],
targets: [
    .target(
        name: "MyTarget",
        dependencies: [
            .product(name: "Gopenpgp", package: "spm-gopengpg"),
        ]
    ),
]
```

Then:

```swift
import Gopenpgp
```

The API is the Objective-C binding generated by `gomobile` for the `crypto`, `armor`, `constants`, `models`, `subtle` and `helper` packages.

## Versions

The tag is the SPM version (`2.10.0`; rebuilds bump the patch). Each release's notes record the gopenpgp fork tag and commit, the gomobile version and the Go version used. A published version's asset and checksum never change.

## Releasing

Releases are built only by the `release` GitHub Actions workflow:

```
gh workflow run release.yml -f version=2.10.0
```

`Package.swift` is generated by the workflow; do not edit it by hand.

## Local testing

Local runs build and verify only; they never publish.

```
./gopenpgp_build.sh build
./gopenpgp_build.sh package
./gopenpgp_build.sh smoke
```

Requires Go, Xcode and the Swift toolchain.
